## How to Add Entries

When adding a new audio file, fill in a row with:

- **File:** Relative path from `audio/`
- **License:** SPDX identifier (e.g., `CC0-1.0`, `CC-BY-4.0`, `Public Domain`)
- **Source:** URL or description of where the file was obtained
- **Author:** Name of the original creator or rights holder
- **Notes:** Any additional context (e.g., modifications made, duration)

## Acceptable Licenses

- Public Domain
- CC0-1.0 (Creative Commons Zero)
- CC-BY-4.0 (Creative Commons Attribution)
- CC-BY-SA-4.0 (Creative Commons Attribution-ShareAlike)
- Explicit written permission from the rights holder (attach proof in PR)
