# Scripts

Setup and validation entrypoints for local development.

## Files

- `setup.mjs` Cross-platform setup orchestration
- `test.mjs` Cross-platform validation orchestration
- `setup.ps1` Windows wrapper for `setup.mjs`
- `setup.sh` Unix wrapper for `setup.mjs`
- `test.ps1` Windows wrapper for `test.mjs`
- `test.sh` Unix wrapper for `test.mjs`
